# تمور العرب — حزمة الموقع التجاري 🛍️

كل الملفات جاهزة للاستخدام. الأسعار والأرقام اللي بعتها كلها موجودة في الموقع.

## 1) الملفات

| الملف | إيه ده |
|---|---|
| `site/index.html` | **الموقع الأساسي** — صفحة واحدة كاملة (منتجات + سلة + طلب على واتساب + فوائد + أسئلة شائعة). ملف واحد فيه كل الصور والخطوط، يشتغل أوفلاين. |
| `site/3d.html` | **نسخة 3D / موشن** — كاروسيل ثلاثي الأبعاد بيلف بالسحب + كروت بتتحرك مع الماوس + هيرو بارالاكس. |
| `motion/tamor-alarab-motion.mp4` | **فيديو موشن جرافيك** — إعلان 44 ثانية، 1920×1080، 30 إطار/ث (جاهز للريلز/ستوري كمان). |
| `posters/*.jpg` | **10 بوسترات منتجات** 1080×1080 بنفس ستايل بوستر العسل اللي بعته. |
| `site/assets/` | الصور الأصلية بعد التنظيف والتوحيد (مربعة 800px). |
| `build.py` | يعيد بناء `site/index.html` و `site/3d.html` بعد أي تعديل. |
| `mograph.py` / `posters.py` | السكريبتات اللي عملت الفيديو والبوسترات (لو حبيت نغيّر حاجة). |

## 2) طريقة النشر (5 دقايق)

- **الأسهل:** افتح [app.netlify.com/drop](https://app.netlify.com/drop) واسحب فولدر `site` كله → هياخد لينك جاهز تبعته للعملاء.
- **مجاني ودائم:** ارفع فولدر `site` على GitHub وشغّل GitHub Pages.
- **دومين خاص:** زي `elgohara.com` — اشتريه واربطه بـ Netlify أو Pages.

## 3) طريقة الطلب في الموقع

1. العميل يختار الوزن من الكارت ويضيف للسلة.
2. يكتب اسمه وعنوانه ويضغط **إتمام الطلب على واتساب**.
3. واتساب يفتح برسالة جاهزة فيها كل المنتجات + الأوزان + الإجمالي + العنوان.
4. كمان فيه زرار **طلب مباشر** على كل منتج لو عايز يطلب حاجة واحدة فورًا.

## 4) إزاي تغيّر حاجة (من غير مبرمج)

- **اسم البراند:** افتح `site/index.html` وابحث عن `const BRAND = "الجوهرة";` وغيّر النص — الاسم هيتغير في كل الموقع لوحده (هيدر، فوتر، رسائل واتساب).
- **الأرقام:** في أول الـ script فيه:
  ```js
  const PHONES = [
    { label: "011 535 00 969", intl: "201153500969", type: "whatsapp" },
    { label: "010 66 77 2300", intl: "201066772300", type: "whatsapp" }
  ];
  ```
- **الأسعار / الأوزان:** ابحث عن `const PRODUCTS = [` — كل منتج فيه `variants` بالأسعار. أي سعر تحطه `null` يظهر للعميل كـ «السعر عند الطلب».
- **نصف وربع لتر زيت الزيتون:** مسجلين بـ `null` لحد ما تبعتلي السعر — قولّي وأنا أظبطهم.
- **بعد أي تعديل:** شغّل `python3 build.py` لو عدّلت في `site/src/*.tpl.html`، لكن لو عدّلت في `site/index.html` مباشرة مفيش حاجة تتعمل.

## 5) ملاحظات على البيانات

- الأسعار كلها بالجنيه المصري، وسايب في الفوتر سطر: «الأسعار قابلة للتغيير حسب السوق».
- البادجات زي «ملكي / VIP / سوبر جامبو» ظاهرة على الكروت.
- الفوائد الصحية مكتوبة بصيغة عامة ومحتاجة مراجعة منك لو حبيت (خصوصًا أي ادعاء علاجي).
- صور اللوز والفستق من صورك (علب بلاستيك بملصق البراند)، وباقي الأصناف صور ستوديو مولّدة بنفس الروح — تقدر تستبدلها بصورك الحقيقية بنفس الأسماء في `site/assets/`.

## 6) لسه محتاج منك

- ✅ الاسم اتغيّر لـ **تمور العرب — لتجارة التمور والمكسرات**، واللوجو اتقص من الملصق واستُخدم في الموقع والفيديو والبوسترات (`site/assets/logo_color.png`, `logo_gold.png`, `logo_mark.png`).
- ✅ كل الأرقام في الموقع (هيدر، فوتر، كارت التواصل) بقت بتفتح **واتساب** برسالة استفسار جاهزة.
- سعر **نصف/ربع لتر** زيت الزيتون لسه ناقص.
- أي أصناف تانية (سمن، حلاوة، مكسرات مقشرة... إلخ) لو عايز نضيفها.

- `011 535 00 969` → `wa.me/201153500969`
- `010 66 77 2300` → `wa.me/201066772300`

«السلام عليكم تمور العرب 🌿 عايز أستفسر عن المنتجات والأسعار المتاحة.»
والسلة بتبعت رسالة فيها المنتجات والأسعار والإجمالي.
